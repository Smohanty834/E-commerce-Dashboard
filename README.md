# E-Commerce Performance Analytics Dashboard

## 📊 Project Overview

An interactive Power BI dashboard developed to analyze e-commerce sales performance, profitability, product performance, regional trends, sales channels, and discount impact using 100K+ sales records.

## 🎯 Objectives

* Monitor key sales and profitability KPIs
* Analyze product and category performance
* Compare regional and sales channel performance
* Evaluate the impact of discounts on profitability
* Identify key drivers of profit
* Generate actionable business recommendations

## 🛠️ Tools & Technologies

* Power BI
* DAX
* Power Query
* Data Modeling
* Excel
* Data Visualization

## 📌 Dashboard Pages

### 1. Executive Overview

Provides an overview of revenue, profit, profit margin, orders, AOV, revenue trends, regional performance, and sales channels.

### 2. Product Performance

Analyzes top products, product categories, product classes, Pareto performance, and profitability.

### 3. Regional & Channel Analysis

Compares regional and channel performance using maps, rankings, heatmaps, and decomposition analysis.

### 4. Profitability & Discount Analysis

Analyzes discount impact, profitability trends, revenue-to-profit flow, and category profitability.

### 5. Insights & Recommendations

Uses Power BI Key Influencers and analytical findings to identify profit drivers and provide strategic recommendations.

## 📈 Key Power BI Concepts

* Star Schema Data Modeling
* DAX Measures

* Moving Average
* Top-N Analysis
* Ranking
* Pareto Analysis

## 💡 Key Insights

* Identified products and categories contributing significantly to overall revenue and profit.
* Analyzed the relationship between discount levels and profitability.
* Identified high-performing regions and sales channels.
* Used Key Influencers to identify factors affecting profit.
* Converted analytical findings into actionable business recommendations.
